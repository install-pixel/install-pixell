# QRaft — правила для роботи в будь-якому чаті

- Окрема програма з набору Black Glass (лаунчер — гілка `ccr-22eab90a-2m7zo1`, папка `blacklaunch`). Згодом частини
  зведемо в одну велику програму, але кожна має жити й окремо.
- Спілкування з користувачем — українською.
- **Мови інтерфейсу: українська, польська, англійська.** Кожен текст — у `res/values*/strings.xml`, жодних рядків у коді.
- **Стилі:** «Аркуш» (рукописний чорний, шрифт Caveat) і «Скло» (Black Glass) — `ui/Sheet.kt`, `AppStyle.glass`.
  Стиль перемикає все повністю: кожна нова річ має малюватись через `pencilFrame` / `outline` / `GlyphIcon` /
  `pencilStroke` (вони самі вибирають олівець чи скло) і перевірятись в обох стилях. Світлі теми — після спільного
  модуля тем (ROADMAP лаунчера, етап E).
- **Мова:** як у телефоні або вручну в Налаштуваннях (лише uk / pl / en) — `settings/AppSettings.kt`.
- Без хмари й мережі: ML Kit — вбудовані моделі, дозволу INTERNET немає.
- Android SDK у хмарному середовищі недоступний: збірка — GitHub Actions (`.github/workflows/qrcodes.yml`), тестовий APK —
  реліз `qrcodes-latest`. Чисті Kotlin-тести (розкладка наклейки, фільтр тексту) можна запускати окремим JVM-проєктом.
- Поведінку Android перевіряє користувач (OnePlus 13, Android 16); не позначати такі пункти виконаними без його звіту.
