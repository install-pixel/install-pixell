# Щоденник

Особистий щоденник у стилі Black Glass: дві теми («Скло» і «Аркуш»), три мови (uk / pl / en), без інтернету.

## Що вміє
- **Обкладинка** з назвою; своє фото на обкладинці, оброблене під тему (у «Склі» — чорно-біле під склом, в «Аркуші» —
  малюнок білим олівцем зі збереженням схожості). Без фото — візерунок (щоденники на полиці розрізняються).
- **Замок** — 4 барабани, як на дипломаті. Код не скидається: забув — щоденник можна лише стерти.
- **Гортання пальцем** — сторінка згинається за пальцем, зворот ледь просвічує, легка вібрація.
- **Сторінка дня**: дата, місце (вручну), одне фото, один запис голосу, текст шрифтом теми по лініях. До двох сторінок на
  день — коли перша заповнюється, щоденник сам перегортає на другу.
- **Чорнило висихає** (через день чи тиждень): висохле не змінити — лише викреслити (олівцем / скляною краплею).
- **Перо** — писати й малювати пальцем поверх сторінки (без розпізнавання).
- **Закладка-стрічка** — смикнути вниз, щоб покласти / прибрати; відкриватися на ній або на сьогодні.
- **Пошук** словами, датами, місяцями, роками, місцем; знайдене підсвічується на сторінці.
- **Календар**, «цей день рік тому», товщина книжки за кількістю записів.
- **Кілька щоденників** на полиці.
- **Резервна копія** — один файл, зашифрований паролем.

Усе зберігається лише на телефоні й зашифроване. Тестовий APK — реліз `diary-latest`.
