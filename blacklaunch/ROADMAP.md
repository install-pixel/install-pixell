# Black Glass — Roadmap 2.0

Затверджено 28.10.2026. Нових функцій більше не додаємо. Лишилось три речі:
1. виправити баги;
2. спростити налаштування;
3. зробити чотири теми, спільні для всіх наших програм (лаунчер, клавіатура, згодом нотатник).

Попередній план і вся історія етапів 0–19 лежать в [`ROADMAP_ARCHIVE_v1.md`](ROADMAP_ARCHIVE_v1.md).
Незроблені ідеї звідти мають статус «колись, можливо». Їх не робимо, доки окремо не погодимо.

**Правило:** одна категорія → перевірка за списком → виправлення → повторна перевірка → закрити → наступна.

## 1. Як ми працюємо

| Хто | Що робить |
|---|---|
| Claude | пише код і тести, перевіряє логіку в коді, комітить, пушить, стежить за збіркою |
| GitHub Actions | збирає APK, запускає тести й lint, публікує `blacklaunch-latest` |
| Користувач (OnePlus 13) | встановлює APK, проходить список перевірок категорії, пише, що не так |

Правила (з першої версії, без змін):
1. Працювати тільки над поточною категорією чи етапом.
2. Перед зміною коду — перевірити фактичний стан.
3. Помилку спершу відтворити або знайти причину в коді, тоді виправляти.
4. Не переписувати працюючі модулі без потреби.
5. Кожне виправлення — зелена збірка й тести; окремий коміт.
6. CHANGELOG оновлюється разом із поведінкою.
7. Не заявляти про перевірку, якої не було: поведінку Android перевіряє користувач.
8. Офлайн, без фонових процесів, без Accessibility і root; лише офіційні API.
9. Усі тексти — українська, польська, англійська.

Позначки: `[ ]` — ще ні; `[~]` — виправлено, чекає перевірки на телефоні; `[x]` — перевірено й закрито.

## 1a. Головне правило оформлення (31.10.2026)

**Тема перемикає все повністю.** Вибрана тема — це весь Black Glass: кожен екран, кожне вікно, кожна підказка й
повідомлення, налаштування, ігри, таймер, гравець. Жодного «половина в одному стилі, половина в іншому»: у рукописному —
усе від руки (шрифт, рамки, значки), у скляному — усе скляне своїм шрифтом.
- Кожна нова чи змінена річ перевіряється в обох стилях, перш ніж вважати її готовою.
- Чого Android не дає перемалювати (системні сповіщення в шторці, системні вікна дозволів, системні спливні
  підказки, коли Black Glass не на екрані), — свідомо мінімізуємо: показуємо своїм вікном, де це можливо.
- [ ] Аудит: знайти й виправити все, що зараз не перемикається з темою (Етап C).

## 5. Етап D — два стилі, чотири теми

Концепція (уточнено користувачем 31.10.2026): **два стилі** — рукописний («Аркуш») і скляний («Скло»); у кожного
**дві теми** — темна й світла. Разом чотири: дві чорні, дві світлі.

| Стиль | Темна | Світла |
|---|---|---|
| **Скло** | **Скло · Темна** (є): чорне тло, скляні плашки | **Скло · Світла**: фото на тлі, усі плашки й кнопки — напівпрозоре скло, крізь яке видно тло (що більше шарів, то менше видно) |
| **Аркуш** | **Аркуш · Темна** (є): чорний аркуш, білий олівець; видалити — червоним, мікрофон — вишневим, головні дії — синім | **Мапа**: стара карта (у дусі Uncharted, записника Індіани Джонса), коричневе чорнило; кнопки — кам'яні чи глиняні таблички з написом |

- [ ] Назви без «OLED». Темні теми — просто чорні: на OLED чорні пікселі вимкнені (ощадливо), на будь-якому іншому
  екрані — звичайний чорний фон. Жодних особливих вимог до екрана.
- [ ] Скло · Світла: ескіз → реалізація. Фото на тлі — з вільною ліцензією; скло — розмита копія тла під плашкою
  (рахується раз, не щокадру) + світлий напівпрозорий шар і відблиск по краю; текст темний.
- [ ] Мапа: ескіз → реалізація. Пергамент малюється кодом (плями, потертості, ледь видна сітка); чорнило коричневе;
  кнопки-таблички (камінь/глина) малюються кодом; шрифт — Caveat або інший вільний.
- [ ] Вибір теми — як вибір набору: при першому запуску й в Оформленні.
- [ ] Застереження в описі: світлі теми на OLED витрачають більше батареї.

### D2. Своє фото на тлі — під фільтр теми (ідея користувача 31.10.2026)
Фото не вставляється як є (псує вигляд) — його один раз, при виборі, перемальовує фільтр теми. Усе на телефоні, без
мережі; готове зображення зберігається й більше не перераховується (батарею не витрачає).

| Тема | Що робить фільтр |
|---|---|
| Аркуш · Темна | чорне тло, контури фото — білим олівцем (як намальовано від руки) |
| Мапа | старе фото: сепія, згини, потертості, плями; тло підганяється під колір пергаменту |
| Скло · Темна | чорно-біле, притемнене (за потреби — легке розмиття) |
| Скло · Світла | «товсте скло»: сильне розмиття, світлий тон, відблиск |

- [ ] Поверх фото — шар під текст (затемнення / розмиття там, де написи, огляд, годинник, батарея), щоб біле на
  білому чи коричневе на коричневому не губилось — без підлаштовування кольорів шрифту під кожне фото.
- [ ] Ескізи кожного фільтра на кількох різних фото → погодження → реалізація.

## 6. Етап E — теми, спільні для всіх наших програм

- [ ] Документ дизайну: кольори, шрифти, рамки, правила кожної теми. Це єдине джерело для всіх програм.
- [ ] Спільний модуль теми (палітри, шрифти, олівцеві рамки й штрихи), поруч із програмами в одному репозиторії.
- [ ] Синхронізація: лаунчер зберігає вибрану тему, інші наші програми її читають і бачать зміну. Без мережі й фону,
  лише для програм із нашим ключем підпису. Немає лаунчера — у програми свій вибір.
- [ ] Клавіатура (гілка `claude/offline-keyboard-android-w9kw2a`) — чотири теми.
- [ ] Нотатник — окремим проєктом згодом, одразу на спільній темі.
