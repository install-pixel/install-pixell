# BlackLaunch

Мінімалістичний Android-лаунчер: чорний екран, пошук програм українською, польською та
англійською (текстом і голосом), профілі «Робота», «Дім», «Відпочинок».
Інтерфейс — мовою телефону: українська, польська, інакше англійська.
Працює повністю локально, без сервера, реклами та аналітики.

## Технічні параметри

| Параметр | Значення |
|---|---|
| Мова | Kotlin 2.1.21 |
| UI | Jetpack Compose (BOM 2025.06.01), Material 3 |
| Збірка | Gradle 8.14.3, Android Gradle Plugin 8.11.1, JDK 17 |
| minSdk | 26 (Android 8.0) |
| compileSdk / targetSdk | 36 |
| Package | `com.blacklaunch.launcher` |

## Як ми працюємо

Android Studio не потрібна. Цикл такий:

1. Claude пише код у хмарному середовищі та пушить у гілку.
2. GitHub Actions (`.github/workflows/blacklaunch.yml`) збирає APK, запускає
   unit-тести та lint.
3. APK з'являється в релізі **`blacklaunch-latest`** (вкладка Releases репозиторію),
   його можна завантажити одразу на телефон.
4. Ви встановлюєте APK, перевіряєте чекліст етапу й пишете результат.
5. Тільки після цього етап вважається завершеним.

Усі збірки підписані одним тестовим ключем (`app/debug.keystore`), тому нова
версія встановлюється поверх старої без видалення. Цей ключ лише для тестів,
для релізу 1.0 буде окремий приватний ключ (Етап 14).

## Як повернути стандартний лаунчер

Налаштування → Програми → Програми за замовчуванням → Головний екран →
вибрати попередній лаунчер. Або просто видалити BlackLaunch.
