# Black Glass — чекліст повного тестування (етап 13, RC1)

Версія для тесту: остання з `BlackGlass.apk`. Телефон: OnePlus 13, Android 16.
Як заповнювати: поставте ✅ (працює), ❌ (не працює — коротко що саме) або ➖ (не користуюсь).
Надсилати можна частинами, по розділах.

## 1. Встановлення й оновлення
- [ ] Нова версія ставиться поверх старої, налаштування й профілі на місці
- [ ] Black Glass — головний екран за замовчуванням; кнопка «Додому» повертає на чорний екран
- [ ] Перезавантаження телефона: Black Glass стартує сам, профіль той самий

## 2. Головний екран
- [ ] Чорний екран, значки профілю на своїх місцях; перетягування й обмін місцями
- [ ] «Показувати програми на екрані» вимкнено → значків немає, увімкнено → повернулись на місця
- [ ] Назва профілю / «Короткий огляд»: дата, годинник, будильник, подія, батарея — як вибрано (загально й «Свій вибір» у профілі)
- [ ] Великий шрифт Android (Налаштування → Дисплей → Розмір шрифту): нічого не обрізається й не налазить

## 3. Профілі
- [ ] Перемикання: подвійний дотик, дотик до назви, плитка в шторці, свайп (якщо ввімкнено), голос «режим …»
- [ ] «У швидкому перемиканні»: гортаються лише позначені; решта — з налаштувань і пошуку
- [ ] Звук профілю (звичайний / вібрація / без звуку) і «Не турбувати» вмикаються й вимикаються
- [ ] Фільтр сповіщень профілю + «Також дозволити від…»: чужі ховаються, при поверненні профілю — з'являються

## 4. Пошук
- [ ] Програми: назва, транслітерація, помилки в слові, власні назви; Enter — запускає найнижчий результат
- [ ] Порожній пошук: підказки, останні запити, «Усі програми» A–Z, приватний простір (якщо є)
- [ ] Калькулятор і конвертер («2+2*3», «10 км в милі»)
- [ ] Налаштування Android і налаштування програми («сповіщення …», «батарея …»)
- [ ] Контакти (з «Подзвонити» / «Написати»), календар, SMS
- [ ] Недавні дзвінки (з «Передзвонити»), тексти сповіщень (і змахнуті)
- [ ] Музика, відео, фото за назвою й датою («фото вчора», «фото за тиждень», «фото жовтень 2025»)
- [ ] «Показати всі» → сітка мініатюр; довге натискання → вибір → «Поділитися», «У кошик»
- [ ] Свайп униз закриває пошук; легкий дотик — ні
- [ ] Профіль «Лише програми профілю» і глобальний пошук «Вимкнено / За програмами / Увімкнено»

## 5. Голос і команди
- [ ] Голосовий пошук: «відкрий …», просто назва — список, «останній додаток»
- [ ] Офлайн: режим польоту — голос працює (офлайн-модель)
- [ ] Вбудовані команди: будильник, таймер (свій, у сповіщенні), ліхтарик, яскравість, музика, гучність, Wi‑Fi/Bluetooth (сторінка), маршрут, подія в календарі, «котра година» (і вголос)
- [ ] Дзвінок контакту (з відліком, якщо «Дзвонити одразу»), SMS, повідомлення в месенджері — надсилаєте ви
- [ ] Групи у «Вбудованих командах» вмикаються/вимикаються; «Детальніше»
- [ ] «Мої команди»: фраза голосом і текстом + Enter — виконується, пошук закривається
- [ ] «Лише якщо» (навушники / зарядка / дротові) і «Запускати саму» (Bluetooth, зарядка, дротові навушники)
- [ ] Програма з команди, що запустилась сама: сповіщення «Торкніться» або одразу з «Поверх інших вікон»

## 6. Налаштування
- [ ] «Дозволи»: стан кожного правильний, дотик відкриває потрібну сторінку Android
- [ ] Приховані програми повертаються; власні значки; сірі значки; чорні шпалери
- [ ] «Очистити історію»
- [ ] Резервна копія: зберегти файл → змінити щось → відновити → усе як було (профілі, команди з умовами, огляд)

## 7. Надійність і батарея
- [ ] День звичайного користування: Black Glass не вилітає (Налаштування → Про програму → журнал помилок порожній)
- [ ] Батарея: Black Glass не в списку тих, що багато витрачають (Налаштування Android → Батарея)
- [ ] Без інтернету все, крім завантаження моделей, працює однаково
- [ ] Поворот / розділений екран / темна-світла тема системи — нічого не ламається

## Відомі обмеження (не помилки)
- Wi‑Fi, Bluetooth і мобільні дані Android дозволяє перемикати лише користувачу — команда відкриває сторінку (OxygenOS показує повну сторінку, а не маленьку панель).
- Відкрити програму з фону (команда, що запустилась сама) — лише дотиком до сповіщення або з дозволом «Поверх інших вікон».
- Закривати чужі програми чи прибирати їх із «Нещодавніх» стороннім лаунчерам Android не дозволяє.
- Чати Google Messages (RCS) іншим програмам недоступні — у пошуку лише звичайні SMS.
- Тексти змахнутих сповіщень пам'ятаються до перезапуску Black Glass (лише в пам'яті, без запису на диск).
