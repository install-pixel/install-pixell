# Changelog

## [0.1.0] — Етап 1 «Black Home»
### Додано
- BlackLaunch реєструється як домашній екран (HOME), вхід через меню програм збережено.
- Повністю чорний екран без елементів, прозорі системні панелі.
- Back на головному екрані нічого не робить.
- Лаунчер не показується в списку останніх програм.

## [0.0.1] — Етап 0
### Додано
- Каркас проєкту Kotlin + Jetpack Compose (minSdk 26, targetSdk 36).
- Чорний екран-заглушка з номером версії.
- CI-збірка debug APK, unit-тести та lint у GitHub Actions; публікація APK у релізі `blacklaunch-latest`.
- Фіксований тестовий ключ підпису для оновлення поверх попередньої версії.
- README, ROADMAP, CHANGELOG.
