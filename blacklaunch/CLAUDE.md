# BlackLaunch — правила для роботи в будь-якому чаті

- Основний документ вимог — `ROADMAP.md`. Один етап за раз, перевірка, коміт, звіт.
- Спілкування з користувачем — українською.
- **Мови інтерфейсу: українська, польська, англійська** (правило для всіх проєктів користувача).
  Мова телефону українська → українська, польська → польська, будь-яка інша → англійська.
  Кожен текст для користувача — у `res/values/strings.xml` (англійська, за замовчуванням),
  `res/values-uk/strings.xml` і `res/values-pl/strings.xml`. Жодних рядків у коді.
  Пошук, псевдоніми та голосові команди теж підтримують усі три мови.
- Без хмари й без сервера; без фонових процесів, що витрачають батарею.
- Android SDK у хмарному середовищі недоступний: збірка — GitHub Actions
  (`.github/workflows/blacklaunch.yml`), тестовий APK — реліз `blacklaunch-latest`.
  Чисті Kotlin-тести (пошук, команди) можна запускати локально окремим JVM-проєктом.
- Тестовий телефон: OnePlus 13, Android 16 (OxygenOS). Поведінку Android перевіряє користувач;
  не позначати такі пункти виконаними без його звіту.
