# Палета — правила для роботи в будь-якому чаті

- Окрема програма з набору Black Glass (лаунчер — гілка `ccr-22eab90a-2m7zo1`, папка `blacklaunch`; QRaft — гілка
  `ccr-282b0169-7mo28f`, папка `qrcodes`). Витягнута зі старої Flutter-програми складу (вкладка «Новий продукт»,
  `lib/features/new_product/` у `master`) — звідти взято лише логіку, усе написано заново на Kotlin / Compose.
- Спілкування з користувачем — українською.
- **Мови інтерфейсу: українська, польська, англійська.** Кожен текст — у `res/values*/strings.xml`, жодних рядків у коді.
  Мова — як у телефоні (uk → uk, pl → pl, інша → en) або вручну в Налаштуваннях.
- **Стилі:** «Скло» (Black Glass, шрифт Exo 2) і «Аркуш» (рукописний, шрифт Caveat) — `ui/Sheet.kt`, `AppStyle.glass`.
  Стиль перемикає все повністю: кожна нова річ малюється через `pencilFrame` / `outline` / `GlyphIcon` / `pencilStroke`
  і перевіряється в обох стилях. Кольори — лише з токенів `ui/theme/Theme.kt` (`Oled`), щоб світлі теми потім міняли
  тільки токени. Спільні правила оформлення й дій — `THEMES.md` у гілці лаунчера; компоненти — копія з QRaft.
- Рядок стану типово сховано (з'являється свайпом від верхнього краю) — і в усіх вікнах.
- Без хмари й мережі: ML Kit — вбудована модель, дозволу INTERNET немає.
- Логіка розкладки й розрахунку — чистий Kotlin без Android (`pack/`), з тестами (`app/src/test`). Їх можна запускати
  окремим JVM-проєктом (Kotlin JVM + JUnit, джерела `pack/` і `test/`) — Android SDK у хмарному середовищі недоступний.
- Збірка — GitHub Actions (`.github/workflows/paleta.yml`), тестовий APK — реліз `paleta-latest`.
- Поведінку Android перевіряє користувач на телефоні; не позначати такі пункти виконаними без його звіту.
- База — Room, версія 2 (`data/`; 1 → 2 — другий шар: `layout2`, `perLayer2`). Кожна зміна схеми — нова версія з явною міграцією; схема — у `app/schemas`.
