# Добавки (Supps)

Простий офлайн-трекер добавок для Android.

- **Сьогодні** — блоки «Ранок» і «Вечір»: відмітити прийняте й поставити 1–5 на кілька питань; відкритий той блок,
  що зараз доречний. Час відміток дає підйом і відбій — з них рахується сон.
- **Історія** — сон, самопочуття, дотримання, витрати, календар, «як почуваєшся з добавкою і без».
- **Аптечка й налаштування** (одна кнопка) — добавки за категоріями (картка: доза, схема, банка, «купив нову»),
  чергування, схема JSON (вставити / файл / копія / шаблон), питання оцінки, день і сон, вигляд.

- Kotlin + Jetpack Compose, Room; без дозволу INTERNET.
- Оформлення — за `THEMES.md` (дві темні теми «Скло» й «Аркуш», компоненти з QRaft). Кнопка «Назад» — унизу.
- Мови: uk / pl / en (`values-uk`, `values-pl`, `values`).
- APK збирає `.github/workflows/supplements.yml`; постійне посилання на останню збірку:
  `releases/download/supps-latest/Supps.apk`.

## Схема JSON (імпорт / копія)

```json
{
  "format": "supps", "version": 1,
  "groups": [ { "key": "adapt", "name": "Адаптогени", "breakDays": 0 } ],
  "supplements": [
    { "name": "Омега-3", "category": "База", "form": "capsule", "mg": 750, "perDose": 2, "slot": "wake",
      "schedule": { "type": "daily" }, "stock": null, "pack": 60, "price": null, "note": "" },
    { "name": "Бакопа", "schedule": { "type": "cycle", "on": 84, "off": 28, "doneDays": 0 } },
    { "name": "Родіола", "schedule": { "type": "group", "group": "adapt", "days": 56, "order": 0, "doneDays": 0 } },
    { "name": "Мелатонін", "schedule": { "type": "asNeeded" } }
  ]
}
```

`category` — будь-який текст для порядку в аптечці. `form`: capsule | tablet | powder | drops | other. `slot`: wake | day | dinner | bed. Невідоме — `null` або не писати.
`doneDays` — скільки днів уже приймаєш (цикл чи черга продовжиться з потрібного дня). Повна копія з Налаштувань —
той самий формат плюс розділ `backup` з усією історією. Найпростіше скласти схему так: «Налаштування → Скопіювати
шаблон схеми», вставити шаблон у будь-який чат з ШІ разом зі списком своїх добавок і вставити результат назад.

## Код

- `data/` — сутності Room, `Schedule` (цикли, чергування, «вистачить до»), `Stats`, `JsonIO`. Логіка покрита тестами.
- `ui/` — компоненти тем (`Sheet.kt`, `Kit.kt`, `Switches.kt`, `Bounce.kt`, `Glyphs.kt` — з QRaft) і екрани.
