# Голосове введення та переклад (етапи 6, 8, 9)

Усе працює на телефоні без мережі. Моделі не завантажуються застосунком: ви копіюєте `.zip` на
телефон і імпортуєте його в **Налаштування → Офлайн-моделі**.

## 1. Встановлення моделей

| Модель | Файл | Звідки | Розмір |
|---|---|---|---|
| Голос, українська | `vosk-model-small-uk-v3-small.zip` | alphacephei.com/vosk/models або artifact збірки «Offline Keyboard Models» | ⚠ уточнити на сторінці моделей |
| Голос, польська | `vosk-model-small-pl-0.22.zip` | те саме | ⚠ |
| Голос, англійська | `vosk-model-small-en-us-0.15.zip` | те саме | ⚠ |
| Переклад UK→PL | `offline-keyboard-mt-uk-pl.zip` | artifact збірки «Offline Keyboard Models» | ≈153 МБ zip |
| Переклад PL→UK | `offline-keyboard-mt-pl-uk.zip` | те саме | ≈155 МБ zip |

Порядок дій:
1. Завантажте zip на будь-якому пристрої. Artifacts збірок доступні після входу в GitHub, у браузері,
   унизу сторінки запуску.
2. Скопіюйте файл на телефон (наприклад, у «Завантаження»).
3. Налаштування → Офлайн-моделі → «Імпортувати .zip» у потрібному рядку. Пакет перекладу сам визначає
   свій напрямок.
4. Для голосу натисніть «Дозволити мікрофон» або дозвольте його при першому натисканні 🎤.

Моделі зберігаються в приватній пам'яті застосунку (`noBackupFilesDir/models`) і не потрапляють у
резервні копії. Під час імпорту zip розпаковується з захистом від шляхів поза папкою (zip slip) і
перевіряється структура.

## 2. Голосове введення

- 🎤 на панелі над клавішами починає запис; ⏹ завершує (сказане вставляється), ✕ скасовує.
- Поки ви говорите, текст видно в полі підкресленим (composing text); після паузи фраза фіксується.
- Мова диктування: як мова клавіатури (типово) або вибрана в налаштуваннях.
- Малі моделі Vosk не ставлять розділових знаків, тому є голосові команди (можна вимкнути):

| Українська | Польська | Англійська | Знак |
|---|---|---|---|
| кома | przecinek | comma | , |
| крапка | kropka | period / full stop | . |
| знак питання | znak zapytania | question mark | ? |
| знак оклику | wykrzyknik | exclamation mark | ! |
| двокрапка | dwukropek | colon | : |
| крапка з комою | średnik | semicolon | ; |
| тире | myślnik | dash | — |
| новий рядок | nowa linia / nowy wiersz | new line | ↵ |
| новий абзац | nowy akapit | new paragraph | ↵↵ |

- Великі літери на початку речень і пробіл перед новою фразою ставляться автоматично.
- У полях паролів та incognito мікрофон вимкнений. Запис зупиняється, коли клавіатура ховається;
  непідтверджений текст тоді не вставляється.
- Аудіо обробляється в пам'яті й не зберігається.

## 3. Переклад українська ↔ польська

- ⇄ на панелі вмикає переклад. Напрямок пропонується за мовою клавіатури (UK → UK→PL, PL → PL→UK),
  розкладка перемикається на мову оригіналу. Довге натискання ⇄ змінює напрямок.
- Набирайте мовою оригіналу: текст у полі підкреслений. **Enter (⇄)** замінює саме цей фрагмент
  перекладом. Нічого іншого в полі не змінюється.
- Якщо перемістити курсор, змінити поле або вимкнути переклад, набраний оригінал залишиться як є.
- Якщо текст змінився, поки йшов переклад, результат відкидається (повідомлення на панелі).
- Голос + переклад: сказана фраза розпізнається мовою оригіналу, перекладається й вставляється.
- Переклад недоступний у полях паролів, incognito та полях типу `TYPE_NULL` (термінали).
- Модель завантажується в пам'ять під час першого перекладу (кілька секунд) і звільняється при нестачі
  пам'яті.

## 4. Як це влаштовано

| Компонент | Де | Примітки |
|---|---|---|
| Розпізнавання | `app/.../speech/VoskSpeechEngine.kt` | Vosk (Kaldi) 0.3.75, 16 кГц, модель кешується |
| Сесія диктування | `app/.../speech/SpeechController.kt` | старт/стоп/скасування, вставка, перевірка дозволу й полів |
| Форматування | `core/.../speech/VoiceText.kt` | команди, великі літери, пробіли; unit-тести |
| Токенізатор | `mt/.../SentencePiece.kt` | власний парсер `.spm` і Viterbi unigram |
| Модель перекладу | `mt/.../MarianTranslator.kt` | OPUS-MT (Marian), ONNX Runtime, int8, greedy, KV-кеш |
| Фрагмент перекладу | `app/.../keyboard/TranslationComposer.kt` | composing text, лічильник змін (generation) |
| Експорт моделей | `tools/mt/export_opus_mt.py` | optimum → ONNX → dynamic int8 + перевірочні файли |

### Перевірка якості та сумісності (CI «Offline Keyboard Models»)

1. Модель експортується в ONNX і квантується в int8.
2. Для 202 фраз (`tools/mt/phrases`, ≥200 за планом) Python робить еталон: токени Hugging Face
   `MarianTokenizer` і переклад тією самою квантованою моделлю (greedy).
3. Kotlin-код перекладає ті самі фрази й порівнює результат з еталоном.

Результати першого запуску (2026-10-21):

| Перевірка | UK→PL | PL→UK |
|---|---|---|
| Токени = Hugging Face | 101/101 | 101/101 |
| Переклад = еталон Hugging Face | 86/101 | 86/101 |
| Середній час фрази (CPU CI, 2 потоки) | 29 мс | 28 мс |

Токенізатор також порівняно з офіційною бібліотекою SentencePiece на 213 рядках
(`mt/src/test/resources/spm`), зокрема з емодзі, повноширинними символами та невідомими письмами.

Повний список перекладів для ручної перевірки є в журналі кроку «Kotlin translator vs Hugging Face»
та в artifact `offline-keyboard-mt-report`.

## 6. Відомі обмеження

- Еталон і клавіатура використовують greedy-пошук; Hugging Face за замовчуванням має beam search
  (num_beams=6), тому якість може бути трохи нижчою, ніж на сайті моделі. Beam search можна додати.
- У пакеті два декодери (з кешем і без), тому кожен напрямок займає ~230 МБ після розпакування.
  Злиття декодерів може зменшити це приблизно на 90 МБ.
- Розміри та швидкість на телефоні ще не виміряні; CI вимірює лише на серверному процесорі.
- Якість малих моделей Vosk у шумному складі треба перевірити на місці.
