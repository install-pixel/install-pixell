# Підтримка комп'ютерних клавіш

Програмна клавіатура Android не може гарантувати поведінку системних комбінацій фізичної клавіатури.
Нижче — що саме робить кожна клавіша і від чого залежить результат.

Позначення: ✅ працює в усіх звичайних текстових полях · 🟡 залежить від застосунку · ⛔ недоступно.

## Введення

| Клавіша | Реалізація | Підтримка |
|---|---|---|
| Літери, цифри, символи | `commitText` | ✅ |
| Shift | одноразовий; подвійний дотик фіксує | ✅ |
| Caps Lock | лише літери (цифровий ряд не змінюється, як на ПК) | ✅ |
| Пробіл | `commitText(" ")`; свайп змінює мову | ✅ |
| Backspace | видаляє виділення або одну графему (емодзі, прапор — цілком); утримання повторює | ✅ |
| Delete | те саме вперед | ✅ |
| Enter | дія поля (Надіслати / Пошук / Далі / Готово) або новий рядок; Shift+Enter — новий рядок | ✅ |
| Tab | `\t` у багаторядковому полі; інакше перехід до наступного поля (`KEYCODE_TAB`); Shift+Tab — назад | 🟡 перехід фокусу залежить від форми |

## Навігація та виділення

| Клавіша | Реалізація | Підтримка |
|---|---|---|
| ← → | `setSelection` за текстом поля; запасний варіант — `KEYCODE_DPAD_*` | ✅ / 🟡 у полях, що не віддають текст |
| Shift + ← → | розширює виділення (якір лишається на місці) | ✅ / 🟡 |
| Ctrl + ← → | на слово | ✅ / 🟡 |
| ↑ ↓ | `KEYCODE_DPAD_UP/DOWN` (лише поле знає перенесення рядків) | 🟡 |
| Shift + ↑ ↓ | події клавіш із Shift | 🟡 |
| Home / End | початок / кінець логічного рядка (до `\n`) | ✅ / 🟡 |
| Ctrl + Home / End | початок / кінець документа | ✅ (для дуже довгих текстів — подія клавіші 🟡) |
| Page Up / Page Down | `KEYCODE_PAGE_UP/DOWN` | 🟡 |
| Insert | `KEYCODE_INSERT` | 🟡 Android не має режиму заміни в `EditText` |

## Редагування

| Клавіша / комбінація | Реалізація | Підтримка |
|---|---|---|
| Ctrl+A, Ctrl+C, Ctrl+X, Ctrl+V, Fn → Sel. all/Copy/Cut/Paste | `performContextMenuAction`; запасний — Ctrl-подія | ✅ (`TextView`, браузери) / 🟡 |
| Ctrl+Z, Ctrl+Y, Ctrl+Shift+Z, Fn → Undo/Redo | Ctrl-події клавіш | 🟡 стандартний `EditText` (Android 7+) підтримує; багато месенджерів — ні |
| Ctrl+Backspace / Ctrl+Delete | видалення слова | ✅ |
| Ctrl/Alt/Win + інша клавіша | подія клавіші з модифікатором | 🟡 |
| Alt + літера (польська) | ą ć ę ł ń ó ś ź ż, як у польській «програмістській» розкладці | ✅ |

## Службові

| Клавіша | Реалізація | Підтримка |
|---|---|---|
| Esc | спершу знімає активні модифікатори; інакше `KEYCODE_ESCAPE` | 🟡 застосунок може ігнорувати |
| F1–F12 | `KEYCODE_F1…F12` | 🟡 корисні в терміналах, віддалених робочих столах, деяких редакторах |
| Win | модифікатор `META` | 🟡 системні комбінації Android (наприклад, Win+D) клавіатурі недоступні ⛔ |
| Ctrl + Alt + Del, Alt+Tab, PrintScreen | ⛔ системні, програмна клавіатура не керує системою |

## Поля особливих типів

- **`TYPE_NULL`** (термінали, ігри): уся взаємодія — події клавіш (`sendKeyChar`, `KEYCODE_*`).
- **Паролі та incognito** (`IME_FLAG_NO_PERSONALIZED_LEARNING`): голос і майбутній переклад вимкнені.
- **Числові поля:** мобільний режим відкривається на цифрах.

Поведінку в конкретних застосунках треба зафіксувати за чеклістом у [TESTING.md](TESTING.md).
