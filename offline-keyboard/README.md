# Offline Computer Keyboard

Нативна системна клавіатура Android (IME) на Kotlin: комп'ютерний і мобільний режими, українська,
польська та англійська розкладки. Працює без мережі: у APK немає дозволу `INTERNET`.

Проєкт окремий від Flutter-застосунку в корені репозиторію й має власну збірку Gradle.

## Збірка

Потрібні JDK 21 (тести графем у `:core` вимагають JDK 20+) та Android SDK (platform 35).

```bash
cd offline-keyboard
./gradlew :core:test :mt:test            # логіка й перекладач, працюють без Android SDK
./gradlew :app:testDebugUnitTest :app:lintDebug :app:assembleDebug
# APK: app/build/outputs/apk/debug/app-debug.apk
```

Якщо Android SDK не знайдено (`ANDROID_HOME` / `local.properties`), Gradle збирає лише модуль `:core`.

GitHub Actions (`.github/workflows/offline-keyboard.yml`) виконує тести, lint, збирає debug-APK,
перевіряє, що в APK немає мережевих дозволів, і публікує APK як artifact.

## Встановлення та перший запуск

1. Встановіть APK (`adb install app-debug.apk` або відкрийте файл на телефоні).
2. Відкрийте застосунок **Offline Computer Keyboard**.
3. Крок 1 «Увімкнути» → увімкніть Offline Computer Keyboard. Android покаже стандартне
   попередження, яке з'являється для будь-якої сторонньої клавіатури.
4. Крок 2 «Вибрати» → виберіть її. Виконані кроки позначаються «✓ Готово».
5. Перевірте введення в полі «Перевірка» або в будь-якому застосунку.

## Користування

- **Панель над клавішами** (власні лінійні іконки, кожна кнопка — на всю висоту рядка):
  1-й рядок — мова («Укр» / «Pol» / «Eng», дотик змінює), повідомлення або підказки слів,
  перемикач комп'ютерна ↔ мобільна (єдиний), налаштування (під час запису — «скасувати»);
  2-й рядок — «Aa Текст», переклад «Укр→Pol», переклад виділеного/буфера, «Голос».
- **Мова:** кнопка мови на панелі, свайп по пробілу, у мобільній розкладці — клавіша мови
  (довге натискання відкриває системний вибір клавіатури); у комп'ютерній — Win+Space або власна
  комбінація з «Комбінацій клавіш» (окремої клавіші мови немає, як на справжній клавіатурі).
- **Вигляд:** тема «Як у телефоні» / світла / темна і п'ять пастельних кольорів (блакитний, м'ятний,
  лавандовий, персиковий, пудровий) — Налаштування → «Вигляд».
- **Підказки слів:** працюють одразу завдяки базовому словнику (≈350 частих слів на мову,
  `core/src/main/resources/dictionary`); власні слова (якщо ввімкнено навчання або додані вручну)
  показуються першими.
- **Українська розкладка:** довге натискання е → є э ё, и → ы, ь → ʼ ъ, г → ґ, і → ї.
- **Голос і переклад:** див. [docs/VOICE_AND_TRANSLATION.md](docs/VOICE_AND_TRANSLATION.md).
- **Shift / Ctrl / Alt / Win:** один дотик діє на наступну клавішу, подвійний фіксує, ще один знімає.
  Esc спочатку знімає активні модифікатори.
- **Комп'ютерний режим:** `Fn` відкриває F1–F12, Ins, Home/End, PgUp/PgDn, Cut/Copy/Paste, Undo/Redo;
  `Sym` відкриває додаткові символи (€, zł, ₴, „ ”, — …).
- **Польські літери:** довге натискання (a → ą, z → ż ź …) або Alt + літера в комп'ютерному режимі
  (як польська «програмістська» розкладка).
- **Українські літери:** ґ, ї, є мають власні клавіші в комп'ютерному режимі; у мобільному: г → ґ, і → ї,
  апостроф на окремій клавіші.

## Структура

```
offline-keyboard/
  core/   чиста Kotlin-логіка без Android: розкладки, модифікатори, контролер, шорткати,
          словник користувача, правила Enter/Tab, межі графем і слів, форматування диктування
  mt/     офлайн-переклад: токенізатор SentencePiece, Marian на ONNX Runtime
  tools/  експорт моделей перекладу й набір тестових фраз
  app/    Android: KeyboardService (IME), KeyboardView (малювання й дотики),
          InputConnectionAdapter, SettingsActivity (Compose), SettingsRepository (DataStore),
          OfflinePolicy, SpeechController, TranslationController
  docs/   звіти та документація
```

Модуль `core` не залежить від Android, тому заміна рушія голосу чи перекладу або зміна інтерфейсу
не зачіпає логіку клавіш, а логіку можна тестувати на звичайній JVM.
