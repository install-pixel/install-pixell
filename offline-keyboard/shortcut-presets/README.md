# Набори комбінацій клавіш

Готові набори для комп'ютерного режиму клавіатури. Усі вони вже вбудовані в застосунок
(**Налаштування → Комбінації клавіш → Готові набори**); набори для Vim і Nano надсилають справжні клавіші (Esc, Ctrl+…) у терміналах (Termux); будь-який файл `.txt` звідси можна також
завантажити на телефон і відкрити кнопкою «Імпортувати з файла».

| Файл | Для чого |
|---|---|
| [general.txt](general.txt) | Ctrl+C/V/X/Z/Y/A та інші вбудовані; Win+V — голос, Win+T — переклад, Win+C — перекласти виділене або буфер, Win+M — режим |
| [excel.txt](excel.txt) | 18 формул на Win+літера (=SUM(, =IF(, =VLOOKUP(, =XLOOKUP( …) і 30 комбінацій Excel |
| [nano.txt](nano.txt) | 15 команд на Win+літера (зберегти, вийти, пошук, заміна, рядки, скасувати …) + шпаргалка |
| [vim.txt](vim.txt) | 18 команд на Win+літера (`:w`, `:q`, `:wq`, `:q!`, undo/redo, пошук, `dd`/`yy`/`p` …) + шпаргалка |
| [vscode.txt](vscode.txt) | шпаргалка VS Code (Ctrl+P, Ctrl+Shift+P, Ctrl+/ …) |

## Формат

```
# коментар
title = Назва (англійською)
title.uk = Назва українською
about.uk = Короткий опис
tip.uk = Ctrl+O — зберегти          ← рядок шпаргалки, нічого не встановлює
Win+W = text "\e:w\n"                ← вставити текст (\n — Enter, \e — Esc, \x0f — Ctrl+O)
Win+V = voice                        ← дія клавіатури
```

Дії: `language`, `mode`, `voice`, `translate`, `translate-clipboard`, `hide`, `text "…"`.
Модифікатори: `Ctrl`, `Alt`, `Shift`, `Win`; клавіші: `A`–`Z`, `0`–`9`, `Space`, `Enter`, `Tab`, `F1`–`F12`.
Комбінація має містити Ctrl, Alt або Win (або два модифікатори без клавіші).

Порада: у польській розкладці Alt+літера дає польські букви (Alt+A → ą), тому для власних комбінацій
краще використовувати Win або Ctrl+Alt.
